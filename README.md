# NEON RUNNER（ネオン・ランナー）

外部ファイル不要の単一HTMLファイルで動作するレトロ風2Dアクションゲーム。Canvas描画、Web Audio APIによるサウンド生成をすべてインラインで実装。

## ファイル

- `mario-game.html` — ゲーム本体（HTML/CSS/JS 単一ファイル、約1,200行）

## ゲーム概要

- **ジャンル**: 横スクロール2Dアクション
- **全4ステージ**: 1-1（夜）→ 2-1（昼）→ 3-1（空）→ BOSS（アリーナ）
- **目的**: 敵を踏んで倒し、コインを集めてゴール旗を目指す。最終面はボス（NEON OVERLORD）を5回踏みつけて撃破する

## 操作方法

| 操作 | PC | スマホ |
|------|-----|--------|
| 左右移動 | ← → / A D | 画面下の ◀ ▶ ボタン |
| ジャンプ | Space / ↑ / W | JUMP ボタン |
| 裏技入力 | U キー | 右下の U ボタン |
| サウンド切替 | HUD右上の🔊クリック | 同左 |

- ジャンプは長押しで高く、短押しで低くなる（可変ジャンプ）
- 敵は上から踏みつけると倒せる。横から当たるとダメージ

## ステージ構成

| ステージ | テーマ | 背景 | 特徴 |
|----------|--------|------|------|
| 1-1 | 夜のネオン | 星空・月・山並み | 基本ステージ、敵少なめ |
| 2-1 | 昼の草原 | 青空・太陽・雲・緑の丘 | 敵多め |
| 3-1 | 空中浮島 | 高空・雲海・浮遊島 | 落下注意 |
| BOSS | 暗赤アリーナ | 脈動する光・紫の柱 | 1画面固定、ボス戦 |

## ボス戦

- ボス「NEON OVERLORD」はHP5。踏みつけるたびにHPが1減る
- ボスはプレイヤーを狙って火球を発射する
- HPが減るほどボスの移動速度・弾の発射間隔が上がる
- HP上部にボスHPゲージが表示される

## サウンド

Web Audio APIのオシレーターで動的に生成（外部音声ファイル不要）。

- **効果音**: ジャンプ、コイン取得、敵踏みつけ、ミス、ステージクリア
- **BGM**: ステージごとに異なるキー・テンポのチップチューン（4トラック）

## 裏技

画面右下の「U」ボタン（またはUキー）でパスワード入力画面が開く。正しいパスワードを入力するとボスステージに直接ジャンプできる。

- パスワード: `ramune`

## 技術仕様

- **描画**: Canvas 2D（960×540、アスペクト比16:9）
- **物理**: AABB衝突判定、重力・摩擦・可変ジャンプ
- **カメラ**: プレイヤー追従（lerp補間）、パララックス背景
- **演出**: パーティクル、画面シェイク（ボス被弾時）、フロートテキスト、ビネット
- **レベルデータ**: テキストマップ形式（`#`=地面、`=`=ブロック、`?`=コインブロック、`o`=コイン、`E`=敵、`F`=ゴール旗、`P`=開始位置、`B`=ボス）
- **タイルサイズ**: 48px
- **対応**: PC（キーボード）＋ スマホ（タッチボタン、`@media (hover:none)` で自動表示）
- **依存**: なし（外部ライブラリ・ファイル一切不要）
